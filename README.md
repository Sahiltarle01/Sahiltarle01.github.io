# Personal Portfolio Website 🌐

## 📌 Description

This is my personal portfolio website built to showcase my skills, projects, and contact information. It acts as an online resume and helps recruiters and collaborators understand my background, interests, and technical abilities.

## 🚀 Features

* Responsive design (mobile & desktop)
* About Me section
* Projects showcase
* Resume download option
* Contact section

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages

## 📂 Project Structure

* `index.html` – Main webpage
* `style.css` – Styling
* `script.js` – Interactivity

## ▶️ How to Run Locally

1. Clone the repository

   ```
   git clone https://github.com/Sahiltarle01/your-repo-name.git
   ```
2. Open `index.html` in any browser
